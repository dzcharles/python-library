## Modules

### Logging Module

The [logging module](logging-module/readme.md) provides a ready-to-use logging configuration with:

- Console logging for the root logger
- Separate rotating files for basic, JSON, server, and application logs
- Source filename, line number, logger name, and function information
- Sensitive-data redaction for configured handlers
- Automatic creation of the `logs/` directory
